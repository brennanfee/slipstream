# Slipstream Linux

Slipstream Linux - Scripts to pave bare-metal hardware with one of a variety of Linux distributions.

## Overview

These scripts are not intended to fully "install" a fleshed out "setup" Linux system, but instead to handle the
low-level bits necessary to get a basic installation of the chosen distribution in place. Think of this as a scripted version of the "Arch Way" installation
for more distributions than just Arch. It will install and configure the things that are hard to change after an
installation takes place leaving all the easier things to be configured using other tooling (Ansible, Terraform, Nix,
whatever).
